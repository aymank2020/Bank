# Bank — دفتر التدريب المحلي

مرحلة أولى تعليمية لتسجيل قبض وصرف بالجنيه المصري ومتابعة الرصيد وكشف
الحركات. كان المستودع يحتوي README فارغًا فقط؛ هذا تطبيق جديد محدود النطاق.
تُحفظ البيانات في المتصفح ولا يتصل التطبيق بخدمات بنكية أو بخادم بيانات.
استخدم بيانات تجريبية، ونافذة واحدة للإدخال المتزامن.

## التشغيل والاختبار

يلزم Node.js20 أو أحدث ومتصفح حديث يدعم JavaScript modules وlocalStorage.
لا توجد اعتماديات تحتاج تثبيتًا.

```powershell
npm start
```

افتح `http://127.0.0.1:8790`. يمكن تعيين `PORT` لرقم آخر عند الحاجة.

```powershell
npm test
```

## الاستخدام

1. اختر قبضًا أو صرفًا وأدخل مبلغًا موجبًا وتاريخًا ووصفًا اختياريًا، ثم احفظ.
2. يتحدث الرصيد والكشف بعد الحفظ الناجح. يعرض الكشف الرصيد بعد كل حركة
   حسب ترتيب الإدخال؛ يعرض أحدث50حركة مع صفحات للحركات الأقدم.
3. صدّر JSON للاحتفاظ بنسخة. لاستيراد نسخة، اختر الملف وراجع عدد الحركات
   ورصيدها، ثم اضغط «اعتماد الملف واستبدال الدفتر». الاستيراد يستبدل الدفتر.

المبالغ تُحوَّل من النص إلى عدد صحيح من القروش دون ضرب كسور floating point.
تُقبل الأرقام العربية والإنجليزية، وحتى منزلتين عشريتين. الحد لكل مجموع قبض
أو صرف هو `Number.MAX_SAFE_INTEGER` قرشًا. يُسمح برصيد سالب لأنه دفتر حركة،
ولا تمثل العملية إصدار ائتمان أو تحويل أموال.

صيغة JSON في [ledger.schema.json](ledger.schema.json)؛ يتحقق validator الفعلي
في ledger.js كذلك من وجود التاريخ في التقويم، وعدم تكرار IDs، وحدود المجاميع.
الصيغة تدعم EGP وإصدار1فقط، حتى10000حركة، ووصف160حرفًا وحد ملف5MB.
يُرفض الملف غير المقبول دون تغيير الدفتر. نص الوصف يُعرض كـtextContent.

## حدود المرحلة الحالية

الحفظ localStorage على أصل المتصفح نفسه (العنوان والمنفذ)، غير مشفر ولا
يُزامن بين الأجهزة. قد يؤدي حذف بيانات المتصفح إلى فقد الدفتر، ولذلك توجد
ميزة التصدير. لا يُفتح ملف HTML مباشرة عبر file://؛ استخدم الخادم المحلي
لأن سلوك تخزين file:// غير موحد. لا تسجيل دخول أو خدمات مالية أو بيانات
حسابات حقيقية أو أسعار/فوائد أو نصائح مالية في هذا النموذج.

انظر [خطة التطوير والمراجعة](DEVELOPMENT_REVIEW_AR.md) للتحقق والفجوات والمراحل
القادمة. ملفات test/fixtures بيانات اصطناعية لاختبار الاستيراد.
